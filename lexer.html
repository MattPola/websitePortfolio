Program Lexer

This project was much more difficult that I initially thought it would be. There were a lot more small parts that I didn't think about when I first started. It was an awesome feeling when I finally got the whole program working. This program completely parses entire programs and separates everything into individual tokens. It also tells you what kind of token it is. It then puts the parsed program into another text file.
